# Steps - Identidad de aplicaciones agrícolas

Addon visual para Odoo 18 que:

- asegura contraste blanco en los títulos de las portadas agrícolas oscuras;
- asigna el ícono Steps de Nómina al lanzador estándar de Payroll;
- archiva únicamente el menú raíz de la antigua aplicación Studio
  `Finiquitos`, sin borrar sus modelos ni registros.

No contiene modelos de negocio y no modifica cálculos de Nómina, Contratos ni
Finiquitos.
