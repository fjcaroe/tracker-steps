# Correcciones históricas de notas de soporte

Fuentes de las inspecciones y correcciones realizadas sobre mensajes concretos. Los IDs son históricos; los resultados y respaldos con texto de clientes están fuera de Git. `format_escaped_notes.py` puede escribir con `--post` y `refine_note_titles.py` escribe al ejecutarse. No ejecutar estos scripts para una tarea nueva: preservar las funciones útiles adaptando IDs, respaldo externo y autorización específica para escribir mensajes. La recuperación no ejecutó llamadas RPC ni modificó tickets.
